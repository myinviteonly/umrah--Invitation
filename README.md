# A Blessed Homecoming — White & Gold Experiment

This is an **alternate color palette** for the existing invitation. The original emerald-and-gold site remains unchanged until you upload these files. Same animations, parents’ photos, five scenes, links, favicon, and no-storage RSVP.

## Publish over your GitHub Pages site

1. Unzip `umrah-invitation-white-gold.zip`.
2. Open https://github.com/myinviteonly/umrah-invitation
3. From the **repository root** (same level as `index.html`), select **Add file → Upload files**.
4. Upload **all files inside** this extracted folder, not the parent folder. Approve overwriting existing files and commit changes to `main`.
5. Wait for **Actions → Pages** to finish; open https://myinviteonly.github.io/umrah-invitation/ in Safari and refresh. A Private Tab can help with old cached styles or images.

**Important:** The ZIP is deliberately flat (no `assets/` folder), just like your current fixed repository.

## Colors you can adjust

The final section in `style.css`, labeled `WHITE & CHAMPAGNE GOLD EXPERIMENT`, holds all theme overrides. Change those colors there to fine-tune the look. To go back to the emerald theme, upload the earlier `umrah-invitation-fixed.zip` files again.
